# Why It Matters

<small>Part 1 of 5</small>

> [!TIP]
> **Learning Objectives**
>
> - **Share:** see how one set of pages works on any device, in an LMS and in print
> - **Move:** see how plain Markdown keeps a guide open to adapt or self-host elsewhere, on a site you control
> - **Reuse:** get the Markdown behind any page, with no access to the source files needed

**Open for reuse:** open textbooks and guides are meant to be reused and remixed (the [5Rs](https://opencontent.org/definition/) of open content), but they often live inside a single platform – harder to adapt, move or self-host elsewhere. What if every page stayed portable?

> [!NOTE]
> **The DIY answer: plain Markdown**
>
> A simple text format for web pages – `**bold**`, `## Heading`, `- list item`. It's supported almost everywhere, from GitHub and note-taking apps to Google Docs. Keep every page on a free site you control.

**Not ready to openly license your work?** Plain Markdown still keeps it yours – it outlasts any one platform, and moves, backs up and adapts easily for years to come.

Best of all for reuse, you (and, with an open licence, anyone) can get the Markdown behind any page – no source files needed – with its callouts, math and diagrams intact, ready for [Docsify-This](https://docsify-this.net/) (which shows Markdown as web pages) or GitHub.

**See the proof:** [a Pressbooks book](https://ecampusontario.pressbooks.pub/universaldesign2/) and [the same book in Open Publishing Space](https://demo.hibbittsdesign.org/variants/grav-open-publishing-quark2-pressbooks-udl/), converted with no revisions – more in [From Pressbooks](open-publishing-space/from-pressbooks.md).

**One guide, many uses:** read it at your own pace, present the original version like slides (← and → move between pages), embed it in an LMS, print it or get its Markdown – all from the same pages. Write once, use it many ways.
