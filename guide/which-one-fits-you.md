# Which One Fits You?

<small>Part 6 of 7</small>

All the starters and converters in this guide are **free and open-source**:

- **"I want to share a textbook or guide"** → Open Publishing Space 2: demo with [one guide](https://demo.hibbittsdesign.org/grav-open-publishing-quark2/) or [several guides](https://demo.hibbittsdesign.org/grav-open-publishing-quark2-guides/) · [download](https://getgrav.org/downloads/skeletons#open-publishing-space-site)
- **"I want a web home for my course – or several"** → Open Course Space: [demo](https://demo.hibbittsdesign.org/grav-open-course-space/) · [download](https://github.com/hibbitts-design/grav-skeleton-open-course-space/releases/latest) (an early release)
- **"I already have a Pressbooks book or LMS course"** → the [Pressbooks](https://pressbooks-converter.hibbittsdesign.org/) or [Common Cartridge](https://common-cartridge-converter.hibbittsdesign.org/) Converter
- **"I want to start using Markdown, with no web server"** → [Docsify-This](https://docsify-this.net/), then the [Open Publishing Course Hub Converter](https://open-publishing-course-hub-converter.hibbittsdesign.org/) when you're ready for a full site – see [a course on Docsify-This](https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-open-course-hub-site/main&homepage=home.md&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&loadFooter=_footer.md&pagination=true&searchbox=true&name=CPT-363), or the [Docsify for Open Education and Publishing](docsify/README.md) guide

Both starters are edited in the browser with Grav's Admin 2 panel, or as Markdown files with any editor or via Git.


**Try it in 5 minutes,** on [the original version of this page](https://read-move-reuse.hibbittsdesign.org/guide/which-one-fits-you):

1. **Add** `.md` to this page's address to see its Markdown
2. **Press** ← and → to move through this guide, like slides
3. **Add** `?embedded=true` to this page's address to see it as it would appear in your LMS
4. **Sign in** to [this site's read-only Admin 2 demo](https://try.hibbittsdesign.org/read-move-reuse/admin) and open a page – such as this one – to see its Markdown


Then set up your own site:

1. **Download** a starter: Open Publishing Space from [getgrav.org](https://getgrav.org/downloads/skeletons), or [Open Course Space](https://github.com/hibbitts-design/grav-skeleton-open-course-space/releases/latest) from GitHub (an early release)
2. **Upload** it to your web host and unzip it (your host's file manager can do this), then open the site
3. **Open** Admin 2 by adding `/admin` to the site's address, set up your account and start writing

**Where to host:** many institutions offer web space for staff and students (often called a Domain of One's Own), and most low-cost web hosts run PHP 8.3 or newer.

**See it moved:** this same guide also runs, with the same content, on [the Quark 2 theme](https://read-move-reuse.hibbittsdesign.org/guide) and [the classic Quark theme](https://one.on-rev.com/grav/read-move-reuse-ops-quark/guide), as an [Open Course Space course](https://demo.hibbittsdesign.org/read-move-reuse/read-move-reuse-ocs/guide), and on Grav Premium Helios as an [open reader](https://one.on-rev.com/grav/read-move-reuse-hor/guide) and a [course hub](https://one.on-rev.com/grav/read-move-reuse-hch/guide).

> [!IMPORTANT]
> **Good to know:** publishing as a website keeps things simple, but there's no one-click ebook (EPUB or formatted PDF – pages print cleanly from the browser), you'll need a PHP web host (PHP 8.3 or newer, no database)[^1], colleagues new to Markdown may need a little help to start, and Grav extras like definition and objectives boxes are shortcodes that other tools would need converted.
