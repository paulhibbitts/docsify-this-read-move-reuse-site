# Which One Fits You?

<small>Part 6 of 7</small>

All the starters and converters in this guide are **free and open-source**:

- **"I want to share an open textbook or guide"** → Open Publishing Space 2: demo with [one guide](https://demo.hibbittsdesign.org/grav-open-publishing-quark2/) or [several guides](https://demo.hibbittsdesign.org/grav-open-publishing-quark2-guides/) · [download](https://getgrav.org/downloads/skeletons#open-publishing-space-site)
- **"I want an open home for my course"** → Open Course Hub 2: [demo](https://demo.hibbittsdesign.org/grav-open-course-hub/) · [download](https://getgrav.org/downloads/skeletons#course-hub-site)
- **"I already have a Pressbooks book or LMS course"** → the [Pressbooks](https://pressbooks-converter.hibbittsdesign.org/) or [Common Cartridge](https://common-cartridge-converter.hibbittsdesign.org/) Converter
- **"I want to start using Markdown, with no web server"** → [Docsify-This](https://docsify-this.net/), then the [Docsify Converter](https://open-publishing-course-hub-converter.hibbittsdesign.org/) when you're ready for a full site – see [a course on Docsify-This](https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-open-course-hub-site/main&homepage=home.md&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&loadFooter=_footer.md&pagination=true&searchbox=true&name=CPT-363)

Both starters are edited in the browser with Grav's Admin 2 panel, or as Markdown files with any editor or via Git.

> [!IMPORTANT]
> **Good to know:** publishing as a website keeps things simple, but there's no one-click ebook (EPUB or formatted PDF – pages print cleanly from the browser), you'll need a [term]PHP[/term] web host (PHP 8.3 or newer, no database)[^1], colleagues new to Markdown may need a little help to start, and [term]Grav[/term] extras like definition and objectives boxes are [term name="Shortcode"]shortcodes[/term] that other tools would need converted.

With thanks to the authors of the openly licensed book and course used as examples, for sharing their work in the open 🙏🏻

Paul Hibbitts – [hibbittsdesign.org](https://hibbittsdesign.org/)

[^1]: Many web hosts let you choose the PHP version in their control panel.
