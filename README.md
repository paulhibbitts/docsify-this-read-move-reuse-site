# Read, Move, Reuse – Docsify-This Version

> The Read, Move, Reuse guides on free, open-source DIY tools for open textbooks, guides and courses, published with [Docsify-This](https://docsify-this.net/#/) and laid out like the [Docsify-This Multiple Page Blog Style Site Template](https://github.com/hibbitts-design/docsify-this-multiple-page-blog-style-site).

View it as a website: https://docsify-this.net/?basePath=https://raw.githubusercontent.com/paulhibbitts/docsify-this-read-move-reuse-site/main&homepage=home.md&name=Read%2C%20Move%2C%20Reuse&sidebar=true&loadSidebar=_sidebar.md&loadNavbar=_navbar.md&pagination=true&searchbox=true

Within a guide, the sidebar lists its parts and Previous/Next buttons follow that order; the Guides and About pages have no sidebar. Each guide's Topics and Resources are in the navbar, outside the reading order.

The original guides are built with Grav Open Publishing Space at https://read-move-reuse.hibbittsdesign.org – this version uses the same content, converted to plain Markdown pages:

- `home.md` – the Guides page, with a card for each guide
- `guide/`, `open-publishing-space/`, `open-course-hub/` – one folder per guide: `README.md` (its home page), a page per part, `topics.md`, `resources.md`, `_sidebar.md` and `_navbar.md`
- `about/` – about this site: `README.md` and its own `_navbar.md`

The cards use the `card-list-guides` (Guides page) and `card-list-sections` (guide homes) card lists, new in Docsify-This 2.2.
