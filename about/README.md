# About This Site

This site was originally prepared for the ETUG Fall Workshop 2026. It holds three short guides to free, open-source DIY tools for open textbooks, guides and courses:

- **[Open Textbooks, Guides and Courses](guide/README.md)** – both website starters, plus the converters that bring in a Pressbooks book or LMS course
- **[Open Textbooks and Guides](open-publishing-space/README.md)** – Open Publishing Space on its own, with the Pressbooks Converter
- **[Open Courses](open-course-hub/README.md)** – Open Course Hub and Open MultiCourse Hub, with the Common Cartridge Converter

This version is published with [Docsify-This](https://docsify-this.net), straight from its Markdown files. [The original site](https://read-move-reuse.hibbittsdesign.org) is built with Open Publishing Space.
