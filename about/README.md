# About This Site

This site holds five short guides to free, open-source DIY tools for open textbooks, guides and courses:

- **[Open Textbooks, Guides and Courses](guide/README.md)** – both website starters, plus the converters that bring in a Pressbooks book or LMS course
- **[Open Textbooks and Guides](open-publishing-space/README.md)** – Open Publishing Space on its own, with the Pressbooks Converter (originally prepared for the ETUG Fall Workshop 2026)
- **[Open Courses](open-course-hub/README.md)** – Open Course Hub and Open MultiCourse Hub, with the Common Cartridge Converter
- **[Grav 2 for Open Education and Publishing](https://read-move-reuse.hibbittsdesign.org/grav-2)** – Grav 2 itself, and the free starters, plugins and converters built on it
- **[Docsify for Open Education and Publishing](docsify/README.md)** – Docsify-This and the Docsify Starter Kits, for Markdown on the web with no web server to set up, plus a path to Grav

This version is published with [Docsify-This](https://docsify-this.net), straight from its Markdown files. [The original site](https://read-move-reuse.hibbittsdesign.org) is built with Open Publishing Space.
